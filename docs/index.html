2.2 Dados biométricos

Os dados biométricos (impressão digital ou reconhecimento facial) são processados exclusivamente pelo sistema operacional do dispositivo e nunca são transmitidos aos nossos servidores.

3. Como Usamos seus Dados

  • Prestação do serviço: armazenar e sincronizar suas informações financeiras
  • Segurança: autenticação e controle de acesso
  • Notificações: lembretes de vencimentos (somente com permissão)
  • IA do FinFlow: seus dados são enviados à API da Groq (LLaMA) apenas para responder suas perguntas dentro do app
  • Melhoria do produto: análise agregada e anônima

4. Compartilhamento de Dados

Seus dados nunca são vendidos a terceiros. Compartilhamos somente com:

ParceiroFinalidade
Supabase (AWS)Banco de dados e autenticação
GroqProcessamento de IA (LLaMA)
ExpoBuild, atualizações OTA e notificações push

5. Seus Direitos (LGPD — Lei nº 13.709/2018)

  • Acesso: solicitar cópia dos seus dados pessoais
  • Correção: corrigir dados incompletos ou desatualizados
  • Exclusão: apagar sua conta — disponível em Configurações → "Apagar Minha Conta"
  • Portabilidade: solicitar exportação dos dados
  • Revogação do consentimento: desativar notificações nas Configurações

Para exercer qualquer direito: luispalacio1617@gmail.com

6. Segurança

Utilizamos criptografia TLS 1.3 em trânsito e AES-256 em repouso (via Supabase/AWS). O acesso é protegido por Row Level Security — cada usuário acessa somente seus próprios dados.

7. Retenção

Seus dados são mantidos enquanto a conta estiver ativa. Após a exclusão, são removidos permanentemente em até 30 dias.
